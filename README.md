# Dev Stack Builder

A modern and responsive **Dev Stack Builder** website built with React, TypeScript, Tailwind CSS, and Vite.

The website allows users to explore different web development technologies and create their own development stack by adding technologies to a personal stack.

## About The Project

Dev Stack Builder is a web application designed to help developers explore different technologies used in modern web development.

Users can view technology information such as:

- Technology name
- Category
- Description
- Difficulty level
- Rating
- Technology icon
- Technology badge

Users can also add technologies to their own stack, remove technologies, and remove all selected technologies.

The project is fully responsive and works across desktop, tablet, and mobile devices.


## Technologies Used

This project was built using the following technologies:

- React
- TypeScript
- Tailwind CSS
- Vite
- React Toastify
- JSON
- ES6+

## Main Features

### 1. Explore Technologies

Users can explore different development technologies through responsive technology cards.

Each card displays:

- Technology icon
- Technology name
- Category
- Description
- Difficulty level
- Rating
- Badge
- Add to Stack button

### 2. Build Your Own Stack

Users can create their own development stack by selecting technologies.

The stack provides:

- Selected technology count
- Technology icon
- Technology name
- Technology category
- Remove button
- Remove All button
- Empty stack message

A technology cannot be added more than once.

### 3. Responsive Design

The website is responsive for:

- Desktop
- Tablet
- Mobile

The technology cards use:

- 3 columns on desktop
- 2 columns on tablet
- 1 column on mobile

The navigation also changes into a mobile-friendly hamburger menu on smaller screens.
